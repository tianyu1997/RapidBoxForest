# Legacy Experiment Snapshot

This directory contains the pre-redesign experiment scripts and notes. They are
kept for reference only. Current paper-facing experiment code is rebuilt in the
top-level `experiments/expXX_*` directories and must not execute these archived
scripts.

Archived content includes:

1. previous Exp.1--Exp.7 runners;
2. previous plan documents and analysis notes;
3. old dispatch helpers that called `safe_box_forest/experiments/sbf_old`;
4. the earlier Exp.4/Exp.6 paper asset generator.
