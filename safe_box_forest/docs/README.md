# SBF Documentation Index

Start here if you are using the public SBF repository:

- `../README.md` - repository overview, dependency layout, quickstart, dynamic-update entry points, and paper build shortcut.
- `API.md` - current C++ facade, Python bindings, OMPL helper functions, and subsystem boundaries.
- `EXPERIMENT_REPRODUCTION.md` - step-by-step instructions for building SBF, rerunning the paper table generator, and reproducing experiment artifacts.
- `PAPER_ARTIFACTS.md` - map from experiment scripts and JSON artifacts to the TRO paper source and generated tables.
- `TESTING.md` - additional testing notes beyond the default `tests/run_all.sh` workflow.

Most other files in this directory are planning notes, status snapshots, or
working documents from the TRO development cycle. They are retained for
engineering history, but they are not the recommended first entry point for a
new user or reviewer.
