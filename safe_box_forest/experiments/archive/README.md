# Archived experiment scripts

This directory stores exploratory or legacy experiment scripts that are not part of the compressed TRO 2026 main experiment pipeline.

The scripts in `legacy_demos/` are retained for reproducibility and ad-hoc visualization, but they are not invoked by the main paper table generator.

Moved here on 2026-05-06:

- `grower_2dof_trace.py`
- `grower_staircase.py`
- `marcucci_five_query_profile.py`
